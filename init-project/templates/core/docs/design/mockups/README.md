# Mockups -- the visual spec

One committed HTML file per user-visible surface, named `<feature-id>-<name>.html`
(e.g. `F003-dashboard.html`). The approved mockup IS the spec for that surface:
the `iteration` skill's GRILL step builds against it and design reviews grade the
shipped screen against it. Approval = the owner picked it (note the pick in the feature's
`notes` field in `docs/features.json`). Superseded mockups stay in git history;
keep only the current one per surface here.
